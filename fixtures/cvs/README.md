# Sample CVs
Four fictional CVs (Grace Turner, Kenji Tanaka, Lucas Becker, Amelia Nguyen) and `senior-ios-engineer.txt`, the matching job.
They mirror the LucidHire landing sample and should rank in that order: 93, 71, 54, 50.
Every name, employer and email is invented; emails use example.com.
Edit the `.html` files, then rebuild all PDFs with `./build.sh` (needs Google Chrome).
For LucidHire testing only.
